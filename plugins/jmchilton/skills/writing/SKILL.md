# Writing

Write for the stated reader and purpose. If either is unclear, infer it from the request and existing document, then ask only when the choice would materially change the result.

- Start with the point the reader needs. Use concrete language and organize each paragraph around one idea.
- Preserve the author's intended meaning and voice. Treat examples of another person's writing as references to analyze, not a voice to impersonate.
- Check names, dates, numbers, quotations, and links against available sources. Mark unresolved facts for review rather than inventing them.
- Prefer specific evidence to promotional language or decorative phrasing. Remove repetition and generic introductions.
- When revising, preserve important qualifications. Call out any substantive change to a claim.

Before delivery, read the result as the intended reader. Check that the opening answers the request, the claims are supported, and no placeholders or private source details slipped into the text.
